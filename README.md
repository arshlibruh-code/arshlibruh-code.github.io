# arshlibruh

My portfolio. A globe you fly across, project to project.

**Live:** https://arshlibruh-code.github.io

Built with MapLibre GL (globe), Three.js (3D text and buttons) and Vite.
Satellite imagery: Esri World Imagery.

## Run

    npm install
    npm run dev      # localhost:3000

Push to `main` and GitHub Actions deploys it.

## Keys

- `P` start the journey, `Esc` exit
